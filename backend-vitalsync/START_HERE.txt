🔑 ENVIRONMENT VARIABLES

Edit .env with these critical values:

  DB_HOST=localhost              (PostgreSQL host)
  DB_PORT=5432                   (PostgreSQL port)
  DB_USER=vitalsync_user         (Your DB user)
  DB_PASSWORD=your_password      (Your DB password)
  DB_NAME=vitalsync_db           (Database name)

  JWT_SECRET=your_32_char_string (Random 32+ chars)
  JWT_REFRESH_SECRET=...         (Random 32+ chars)
  ENCRYPTION_KEY=your_32_chars   (Random 32 chars)

  ANTHROPIC_API_KEY=sk_...       (Get from console.anthropic.com)

📊 API ENDPOINTS (21 total)

Authentication (6):
  POST   /auth/signup              Register user
  POST   /auth/login               Login user
  POST   /auth/refresh             Refresh token
  POST   /auth/logout              Logout
  GET    /auth/me                  Current user
  PUT    /auth/profile             Update profile

Vitals (5):
  POST   /vitals                   Record vital
  GET    /vitals/latest            Latest vital
  GET    /vitals/history           History
  GET    /vitals/stats             Statistics
  DELETE /vitals/:id               Delete vital

Devices (4):
  POST   /devices/connect          Connect device
  GET    /devices                  List devices
  POST   /devices/:id/sync         Sync data
  POST   /devices/:id/disconnect   Disconnect

Recommendations (3):
  POST   /recommendations/generate Generate
  GET    /recommendations          Get list
  PUT    /recommendations/:id/acted Mark acted

Notifications (3):
  GET    /notifications            Get list
  GET    /notifications/unread/count Unread
  PUT    /notifications/:id/read   Mark read

❓ TROUBLESHOOTING

Database Connection Error:
  • Check PostgreSQL is running
  • Verify DB_HOST, DB_PORT in .env
  • Check DB_USER and DB_PASSWORD

Port Already in Use:
  • Change PORT in .env
  • Or: lsof -i :5000 && kill -9 <PID>

Module Not Found:
  • Run: npm install
